### Roll20 HTML 분석

- 사담(OOC): `general` + `color: #aaaaaa` 인라인 스타일로 구분
- CoC 7th 판정 블록 구조 분석: `sheet-rolltemplate-callofcthulhu`

  - 성공 레벨: HTML에 없음 → roll ÷ skill 직접 계산

### 파서 구현 (`src/utils/parseRoll20.js`)

- 성공 레벨 계산: 대성공(≤skill/5) / 어려운 성공(≤skill/2) / 성공 / 실패 / 대실패
