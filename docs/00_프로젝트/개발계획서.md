# TRPG 로그 EPUB 변환기 — 개발 계획 정리 (웹앱 버전)

## 프로젝트 개요

- **목표**: Roll20 / 코코포리아 세션 로그를 EPUB으로 변환하는 웹앱
- **배포 형태**: 웹앱 (GitHub Pages — 무료)
- **자동 업데이트**: GitHub에 푸시하면 즉시 반영 (별도 작업 없음)
- **개발 시작일**: 2026년 5월

> **핵심 전제**: 모든 파일 처리(파싱, EPUB 생성, 이미지 처리)는 사용자 브라우저에서 실행.
> 서버 없음, 서버비 없음, 사용자 데이터 수집 없음.

---

## 핵심 기능 목록

### MVP (1개월차 — Roll20)
- Roll20 아카이브 HTML 파일 드래그앤드롭 업로드
- 브라우저 내 HTML 파싱 → 발언자 / 대사 / 타임스탬프 추출
- 표지 이미지 업로드 + 목차 자동 생성
- EPUB 파일 브라우저 다운로드
- GitHub Pages 배포

### 2개월차 추가 기능
- 코코포리아 지원 (JSON 파일 업로드 또는 HTML 파일 업로드)
- 삽화 삽입 기능 (원하는 위치에 이미지 추가)

### 이후 추가 예정
- 커스텀 테마 / 폰트 설정
- 다중 세션 병합
- 변환 기록 저장 / 회원 관리 (Supabase 연동 — 이 시점부터 소폭 비용 발생 가능)

## 기술 스택

| 역할 | 기술 | 비고 |
|------|------|------|
| UI 프레임워크 | React + Vite | 가볍고 빠름 |
| HTML 파싱 | DOMParser (브라우저 내장) | cheerio 불필요 — 브라우저에서 바로 사용 가능 |
| EPUB 생성 | epub-gen-memory (브라우저 빌드) | 브라우저에서 실행 가능 |
| 스타일 | Tailwind CSS | 빠른 UI 작업 |
| 배포 | GitHub Pages | 완전 무료 |
| 향후 백엔드 | Supabase | 회원관리 / 기록 저장 필요 시 추가 |

> **cheerio → DOMParser 변경 이유**: cheerio는 Node.js 환경 전용이라 브라우저에서 직접 실행 불가.
> 브라우저 내장 DOMParser가 동일한 역할을 하므로 대체.

## Roll20 HTML 파일 저장 방법 (유저 가이드용)

앱 안에 아래 내용을 안내 문구로 넣어두면 UX 커버 가능:

1. Roll20 캠페인 페이지 접속 (로그인 필요)
2. 우측 상단 채팅 아이콘 → **Chat Archive** 클릭
3. **"Show on One Page"** 버튼 클릭
4. `Ctrl+S` (Mac: `Cmd+S`) → "웹페이지, 전체" 로 저장
5. 저장된 `.html` 파일을 이 앱에 드래그앤드롭

**목표**: 앱이 브라우저에서 열리고, HTML 파일을 드래그앤드롭하면 파일 내용을 읽을 수 있는 상태

```bash
npm create vite@latest trpg-epub-maker -- --template react
cd trpg-epub-maker
npm install
npm run dev
```

GitHub Pages 배포 설정:
```bash
npm install --save-dev gh-pages
# package.json에 homepage + deploy 스크립트 추가
npm run deploy
```

### 2주차 (5/14~5/20) — HTML 파싱

- [ ] DOMParser로 Roll20 HTML 파싱
- [ ] 발언자 / 대사 / 타임스탬프 추출 로직 작성
- [ ] 파싱 결과를 화면에 미리보기로 출력
- [ ] 파싱 결과 JSON으로 확인 (콘솔 또는 화면 출력)

**목표**: HTML 파일 업로드 시 발언자와 대사가 올바르게 추출되어 화면에 표시되는 상태

```javascript
// 브라우저에서 DOMParser로 HTML 파싱 예시
const parser = new DOMParser();
const doc = parser.parseFromString(htmlString, 'text/html');
const messages = doc.querySelectorAll('.message'); // 실제 클래스명은 분석 후 확인
```

**목표**: 버튼 클릭 시 EPUB 파일이 브라우저에서 다운로드되는 상태

```javascript
// 브라우저에서 파일 다운로드
const blob = new Blob([epubBuffer], { type: 'application/epub+zip' });
const url = URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'session-log.epub';
a.click();
```

## 수익화 방향

- **1단계**: 무료 배포 + 커뮤니티 반응 확인
- **2단계**: 반응 있으면 freemium 구조 적용
  - 무료: 기본 변환 기능
  - 유료: 삽화 삽입, 커스텀 테마, 다중 세션 병합 등
- **후원 모델**: ko-fi / 포스타입 병행 (코코로그 방식 참고)

> 유료 판매 단가는 3,000~5,000원이 현실적. 그보다 중요한 건 커뮤니티 유저 확보.
